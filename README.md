# Carpool

A modern carpooling platform that connects drivers and passengers traveling on the same route.

## Monorepo

- `apps/web` — Next.js web application
- `apps/api` — NestJS API
- `packages/shared` — shared TypeScript types, validation, and utilities
- `docs` — project documentation
- `.github/workflows` — CI/CD workflows

## Stack

TypeScript · Next.js · NestJS · PostgreSQL · Prisma · pnpm
